# Personal Task Tracker

A simple personal project for keeping track of my daily tasks, built while
learning Git and GitHub.

## Project Description

Personal Task Tracker is a small command-line application that lets me add
tasks, mark them as done, and see what is still pending. I started it as a way
to practise the basic Git workflow — creating a repository, cloning it, making
changes, and pushing those changes back to GitHub.

## Features

- Add a new task with a title and due date
- Mark a task as completed
- List all pending tasks
- List completed tasks

## Tech Stack

- **Language:** Python 3
- **Storage:** a local JSON file (no database needed)
- **Version control:** Git and GitHub

## How to Run

```bash
git clone https://github.com/tharuncoder676/personal-task-tracker.git
cd personal-task-tracker
python tracker.py
```
